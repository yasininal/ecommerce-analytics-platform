İşte PDF dokümanına göre projede tamamlamamız gereken eksik kısımların tam listesi:

1. Yapay Zeka Ajanları (En Büyük Eksik - PDF Bölüm 5.3)
Doküman, LangGraph kullanarak tam 5 farklı yapay zeka ajanı (Multi-Agent) yazılmasını şart koşmuş. Ancak projede sadece 2'si (SQL ve Analysis) var. Şunları bizim yazmamız gerekiyor:

Guardrails Agent: Chatbot'a "Bana bir fıkra anlat" gibi e-ticaret dışı alakasız sorular sorulduğunda sistemi koruyup kibarca reddedecek güvenlik ajanı.
Visualization Agent: Dokümandaki o güzel ekran görüntülerinde olduğu gibi (sayfa 14), verileri analiz edip Plotly kütüphanesi kullanarak dinamik grafikler (pasta, çubuk grafikleri) çizecek ajan.
Error Agent: Eğer SQL ajanı hatalı bir sorgu üretirse, hatayı okuyup kodu kendi kendine düzelterek (maksimum 3 deneme) tekrar çalıştıracak olan kurtarıcı ajan.
2. Kaggle Veri Entegrasyonu (ETL Pipeline - PDF Bölüm 2.4)
Hocanız projenin en büyük kısımlarından biri olarak 6 farklı gerçek Kaggle veri setinin (Amazon, Olist vb.) birleştirilip veritabanına aktarılmasını (ETL) istemiş. (%20 puan buradan geliyor).

Eksik: Şu an sadece elle yazılmış 5-10 satırlık sahte veriler (03_seed_data.sql) var. Verileri temizleyecek (kayıp verileri silme, tarihleri düzeltme, para birimlerini eşitleme) ve veritabanına basacak olan ETL Python script'i hiç yazılmamış.
3. Backend ve AI Haberleşmesi (Mimari Uyumsuzluk - PDF Bölüm 5.9)
Dokümanda İstenen: Chatbot'un ürettiği SQL kodunun doğrudan Python tarafından çalıştırılmaması, güvenlik için Java (Spring Boot) backend'ine (/api/chat/ask endpointi) gönderilip orada çalıştırılması isteniyor.
Şu Anki Durum: Chatbot kodları veritabanına doğrudan bağlanıyor. Hocanızın mimari çizimine (Sayfa 9 - 5.9) tam uymak için bu iletişimi Java üzerinden geçirecek bir köprü yazmamız gerekebilir.
4. Diğer Kontrol Edilmesi Gerekenler
Swagger API Dokümantasyonu: Java tarafında tüm API'leri gösteren Swagger arayüzünün (OpenAPI) açık olması istenmiş.
JWT Refresh Token: Kullanıcı girişleri yapılmış ama süresi biten oturumları yenileyen "Refresh Token" mekanizmasının (Bölüm 3.1) kesin olarak olması gerektiği yazıyor.
Özetle: Sitenin klasik web kısımları büyük oranda bitmiş ancak projenin adını taşıyan "Advanced/AI" (Veri bilimi, ETL ve Multi-Agent) kısımları tamamen bize kalmış.
