# 🎨 TrendAnalytix Frontend (Angular)

A premium, modern e-commerce dashboard and marketplace built with Angular 17.

## ✨ Highlights
- **Premium Design:** Glassmorphism effects, modern typography (Inter), and vibrant "Etsy-inspired" color palette.
- **Dynamic Marketplace:** Advanced search, filtering by brand/price/category, and real-time inventory badges.
- **Role-Based Dashboards:** 
  - **Admin:** Global platform management.
  - **Corporate (Seller):** Product management, store analytics, and order fulfillment.
  - **Individual (Buyer):** Shopping experience, address book, and order tracking.
- **AI Integration:** Integrated chatbot interface for natural language data analysis.
- **Checkout Flow:** Interactive cart with coupon support and secure Stripe payment redirection.

## 🛠 Tech Stack
- **Framework:** Angular 17+ (Standalone Components)
- **Styling:** Modern Vanilla CSS (CSS Variables)
- **State Management:** Reactive services with RxJS
- **Icons:** Modern Emoji-based and custom CSS icons

## 🚀 Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   ng serve
   ```
3. Open `http://localhost:4200`
